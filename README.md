## Aston - Discovery Server

Часть микросервисного RESTful Spring Boot приложения.

Центральный реестр микросервисов, в него будут попадать:
- user-service
- notification-service
- api-gateway
- config-server
- eureka-server

Запуск через [aston-serviceOrchestration](https://github.com/gedfalk/aston-serviceOrchestration)
